About this tool

The tool is used as a precheck on scanned documents to look for errors like:

  • unscanned pages
  • wrong pagination
  • double scans
  • ...

Homepage

On the homepage, the user sees the following:

  1. Quick navigation menu
  2. Precheck pdf - the actual tool
  3. Project analysis

Navigation

Through the navigation the user can navigate to the following pages:

  • Precheck - the actual precheck tool
  • Last Run - the last run of checked documents
  • All Runs - all runs of checked documents
  • Settings - customise and manage personal preferences

Precheck page

On the precheck page, the user sees the following:

  1. Select project - Select which project you want to add the scanned files to.
    A project can be created in the settings
  2. File selector - Select the files you want to check for errors, you can select up to 20 files a time.
    The selected files will be shown in the "Selected files" box on the right.
  3. Remove file - Each selected file can be removed from the list by clicking on the red button next to it.
  4. Check - To start the checking process, click the button "Check".

Progress page

The progress page shows the progress of the tool checking the selected files.

Each item of the list shows it's status:

  • - The file is in the queue for being checked.
  • - The file is currently being processed.
  • - The file is checked.
  • - There was an error for checking the file. The file could not be checked and is skipped.

After all the files have been processed, the user can navigate to the overview to see al the files that have been checked.

All Runs page

The All Runs page gives an overview of all checked files. A user can search for specific files in the search box.

The headers:

  • Name - name of the file
  • Errors - the amount of errors found
  • Status - gives the status if a file has been manually checked or not
  • Date - date of check execution
  • Project - to which project a file belongs to

Details page

The details page summarises information of the file and a compressed version of the file for quick lookup for manual checks.

In the “log box” each error is displayed to give more information about the found error. each log is clickable and will redirect the user to the page of the given error.

There are 3 kinds of logs:

  • Warning - returns a found error in the file.
  • Info - gives back more context about a specific step in the process.
  • Success - returns every successful found page number.

When a file is manually checked, the user can click the "Manually check" button and the file will be marked as checked.

Settings

On the settings page, a user can customise and manage personal preferences like:

  • Projects - gives an overview of all created projects. A new project can be added by giving a name and export path and pressing the plus button. A project can also be deleted by the red cross button next to each project.
  • Log level - Log level determines which log messages are shown in the log box on the details page. The log levels :
    1. - Show only warning logs
    2. - Show warning and info logs
    3. - Show all kinds of logs

After making changes, click save.
