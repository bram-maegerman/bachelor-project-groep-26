Precheck pdf

The program uses Tesseract to perform OCR on an image. That is an open-source OCR system created by Google, which, like Abby FineReader, can detect characters in images with a certain accuracy.

To see where we should look for page numbers, we selected ten random pages from different PDFs and stacked them on top of each other, each with a transparency of ten percent. This way we could visually identify where text appears frequently. However, we were only interested in the page numbers, which were usually located in the first or last lines of a page.

To save time and resources, we decided it was best to only scan these relevant areas (header and footer) from the image. We then merged them, with some white space in between to maintain the A4 structure for optimal OCR performance. This gave us fairly accurate results, which further improved when we changed the OCR engine mode (OEM) from 3 to 2.

For the detection of dubble scans, we performed an analysis on multiple PDFs and looked for an average height and width of the pages. We then use these values to detect outliers so we can accurately find these dubble scans.

We now use this average as a hardcoded value from which only a slight deviation (20%) may be made. If the difference is too great, this page will be flagged with a warning that this is probably a double scan.
